# Portfólio — Especialização em Ciência de Dados (IFRN)

Atividades da Pós-Graduação Lato Sensu em Ciência de Dados do IFRN, Campus Natal-Central (DIATINF), em Python com Jupyter e Google Colab. Cada disciplina entra aqui só depois de encerrada e avaliada.

## Estrutura

Uma pasta por disciplina, `POS.NNNN-slug/` (código do SUAP). Dentro, `aula-NN/` guarda o material trabalhado em aula e `atividade-NN/` as entregas. Datasets públicos ficam junto da atividade, com a fonte citada no notebook ou num README da pasta.

## Como rodar

**Google Colab:** abra o `.ipynb` em <https://colab.research.google.com> (File → Upload, ou GitHub → cole a URL deste repositório). Os pacotes usados já vêm instalados no Colab.

**Local (Anaconda/Miniconda):**

```bash
conda env create -f environment.yml
conda activate ifrn-cd
jupyter lab
```

O cwd de cada notebook é a própria pasta dele; os caminhos dos dados são relativos a ela.
